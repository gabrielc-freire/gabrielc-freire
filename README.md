## `01` — Sobre mim

Olá! Sou Gabriel Cardoso Freire, técnico em Desenvolvimento de Sistemas e estudante de Desenvolvimento de Software Multiplataforma.

Tenho experiência prática no desenvolvimento full-stack, participando de diferentes etapas do ciclo de vida de software, desde o levantamento de requisitos e a modelagem de dados até a implementação e a integração de funcionalidades.

Busco desenvolver soluções que combinem organização, funcionalidade e boas práticas de programação, transformando necessidades reais em aplicações úteis.

- Desenvolvimento de aplicações mobile e soluções back-end.
- Integração de APIs e bancos de dados relacionais.
- Modelagem de dados, regras de negócio e arquitetura de aplicações.
- Colaboração em equipe com Git, GitHub e metodologias ágeis.
- Interesse em desenvolvimento de software, IoT e novas tecnologias.

Atualmente, busco oportunidades de estágio e desenvolvimento profissional na área de tecnologia.

## `03` — Projetos em destaque

### PentaPizza — Automação de pedidos

Aplicativo mobile desenvolvido para digitalizar e organizar o fluxo de pedidos de estabelecimentos alimentícios.

- Visualização de cardápio e personalização de pedidos.
- Gerenciamento de comandas e acompanhamento de status.

**Tecnologias:** React Native, TypeScript, Node.js, Express, Prisma e Supabase.
