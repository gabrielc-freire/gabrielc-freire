## 🚀 Projetos em destaque

### 🕒 Relógio digital retrô
Projeto de interface desenvolvido para praticar estruturação com HTML, estilização com CSS e funcionalidades com JavaScript.

**Foco:** manipulação do DOM, atualização dinâmica da interface e identidade visual.

### 🎵 Player de música
Reprodutor de músicas desenvolvido para praticar controles de reprodução, manipulação de áudio e atualização do progresso da faixa.

**Foco:** JavaScript, eventos, controle de áudio e interface interativa.

### 🍕 Sistema de gerenciamento de pizzaria
Projeto acadêmico em equipe com foco no desenvolvimento de uma solução de gerenciamento para uma pizzaria.

**Foco:** organização do projeto, desenvolvimento colaborativo e aplicação prática dos conhecimentos de programação.
